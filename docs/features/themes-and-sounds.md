# Themes & sounds

Light/dark Material UI theme and short Web Audio cues for UI actions.

## Overview

- Sun/moon toggle switches theme (persisted).
- Speaker toggle mutes click / scan / credit / error sounds.
- Theme and mute are stored with the shared Flypaper browser store.
