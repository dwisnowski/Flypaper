# Settings

App preferences from a gear icon in the top nav.

## Overview

- Gear opens a popover on Map and Globe (shared AppBar).
- **Distance unit** toggles Miles / Kilometers for the scan-radius slider, filter distance, and aircraft distance labels.
- Miles is the default; minimum scan radius is **5 mi** (or **10 km** when using kilometers).
- Preference is stored in the shared browser store. OpenSky API calls still use kilometers internally.
