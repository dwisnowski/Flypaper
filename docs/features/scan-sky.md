# Scan sky

Spend OpenSky credits **only when you press the button**. Reloading the page reuses the cached snapshot and does not call OpenSky again.

## Overview

- Estimates cost before you scan (`~1–4` credits by bounding-box area).
- Pulls live `/states/all` for your observer location and radius.
- Saves the snapshot in browser storage so Map and Globe stay in sync.
